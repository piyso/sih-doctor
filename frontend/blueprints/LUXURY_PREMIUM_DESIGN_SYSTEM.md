### 3.1 The OpenType Precision Complications
All clinical vitals, timers, token numbers, and dosage calculations must strictly enforce the following CSS OpenType configuration:

1. **Slashed Zero (`0`):** In clinical medicine, confusing the digit `0` with the letter `O` or `D` can lead to fatal tenfold medication dosing errors (e.g., `10mg` vs `100mg`). The slashed zero complication makes the numeral universally distinct under all lighting conditions.

When a timer or heart rate monitor updates from `71` to `78`, proportional fonts cause the entire line to jump horizontally. `tnum` locks every digit to an identical optical width, ensuring zero layout jitter and rock-solid visual stability.
3. **Indic Script Baseline & Matra Protection:**
   When rendering Hindi (Devanagari), Bengali, Tamil, or Telugu, standard CSS line-heights clip top vowel matras (like *matra* `े` or `ै` or *anusvara* `ं`) and bottom signs (like `ु` or `ू`). We implement a calibrated vertical leading buffer:

```typescript
    if (!this.ctx) {

    gain.gain.exponentialRampToValueAtTime(0.001, now + 0.014);

    osc.connect(filter);
    filter.connect(gain);
    gain.connect(this.ctx.destination);

    osc.start(now);
    osc.stop(now + 0.014);
```
